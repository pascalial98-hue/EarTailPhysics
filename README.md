# 耳尾物理增强 · Ear & Tail Physics

独立 Dalamud 插件，提供分别设置的耳朵和尾巴物理，保留游戏原动画跟随。无需物理 PMP，也不依赖 Penumbra。自定义耳尾的模型、贴图和必要骨架仍由外观 Mod 提供。

**0.1.8 加强长毛尾和猫耳的随机动作。** 长毛尾以尾根为支点，从第一段带动毛层，中后段再跟上。单耳轻抖、双耳轻竖的幅度和持续时间也已提高。打开 `/earphysics`，选择「长毛猫尾／狐尾」，勾选「随机耳尾小动作（试验）」即可测试。

**0.1.7 修复追加猫耳物理组后切职、换装时的描述表越界。** 游戏在装备刷新期间继续使用与运行实例配套的基础物理描述表。打开 `/earphysics` 的「运行状态（排查）」可以查看组数。使用 YAB+ 女猫并开启追加双耳时，预期显示「来源 7 · 当前描述 8 · 运行 8」。切职和换装的实际表现待游戏验证。

0.1.4 的游戏测试已观察到一处石墙产生橙色接触标记与实际修正计数，但用户仍报告许多角色无法穿越的墙、柱子或家具漏判。碰撞排查按用户要求暂缓，本版未修改碰撞算法，也不表示场景覆盖已解决。

## 安装

在 Dalamud 设置 → 实验性 → 自定义插件仓库，添加：

```text
https://raw.githubusercontent.com/pascalial98-hue/EarTailPhysics/main/repo.json
```

刷新插件列表，安装「耳尾物理增强 · Ear & Tail Physics」。输入 `/earphysics` 打开设置。

仅支持 **国服客户端 2026.11.03 / Dalamud API 15**。客户端 EXE 与已核对版本不一致时，插件会显示未适配并停止接管。国际服尚未适配。

测试前关闭旧「耳尾物理增强」、旧耳朵物理和旧尾巴物理 PMP，重绘一次自身。保留自定义耳尾的外观包。随后插件内部切换设置在下一次角色物理更新时应用。

## 设置

| 设置 | 选项 | 默认 |
|---|---|---|
| 耳朵 | 独立开关；轻柔、自然、明显、强烈四档 | 自然 |
| 尾巴类型 | 短毛猫尾、长毛猫尾／狐尾、龙尾 | 长毛猫尾／狐尾 |
| 尾巴惯性 | 原版对照、轻惯性、强惯性 | 强惯性 |
| 身体碰撞 | 关闭、细尾、中等、粗尾 | 关闭 |
| 地面碰撞 | 对游戏地形碰撞面进行查询 | 关闭，试验性 |
| 场景碰撞 | 对游戏已有碰撞体进行扫掠查询 | 关闭，试验性 |
| 接触半径 | 尾根 b、靠根 c、中段 d、后段 e、虚拟末端分别设置 | 保留旧版中后段粗细比例 |
| 根部保护 | 尾根与靠根段可分别取消保护 | 两项均开启 |
| 碰撞体预览 | 节点球体、骨段扫掠胶囊、节点标签 | 关闭；只在设置窗口打开时显示 |
| 随机耳尾小动作 | 静止时随机摆尾、挑尾尖、轻甩、单耳轻抖、双耳轻竖 | 关闭，试验性 |
| GPose 暂停 | 进入 GPose 后恢复来源物理，退出后重新接管 | 开启 |

首版仅作用于自身。已针对猫魅、敖龙、硌狮男女的标准 `n_sippo_b–e` 尾链进行离线参数对照；猫耳使用 `j_mimi_l/r`。不承诺任意新增骨链、多尾、所有玩家种族附加尾巴自动兼容。

耳尾使用游戏原生求解器，复用原动画吸引与风响应。长毛保留已有重量感、中段风响应和收稳调校。0.1.5 只降低耳朵的风系数，四档分别为 0.003、0.006、0.009、0.0135；阻尼、响应速度与基础动画吸引不变。关闭插件后重建加载来源的原始物理；若来源本身是其他物理 Mod，恢复的也是该来源。

0.1.2 保持旧 Mod 的风响应数值，在原生环境风更新前应用设置，并在重建时衔接已有风输入。没有增加固定风力或人为摆动，也没有提高弹性。尾链替换后重新绑定接触回调。用户已确认该版本接管和风摆正常；0.1.3 保持这条路径。

身体碰撞仍只作用于中后段，使用独立的粗细预设。地面／场景接触默认保护尾根和靠根段，也可分别取消保护，让它们参与接触。取消根部保护可能使尾根偏离连接处或抖动。地面查询支持有碰撞面的斜坡与平台；场景仅能识别游戏已有碰撞体，不能保证任意家具、装饰、服装、其他角色或透明毛发轮廓碰撞。

### 按尾巴形状调碰撞

打开「尾巴节点碰撞与预览」，勾选「显示碰撞体预览」，调整五个节点的半径（0–30 cm）。受保护的节点不参与地面／场景接触，半径栏暂时锁定；取消相应保护后即可调整。半径 0 关闭该节点的直接接触，骨链长度约束仍会联动。

每个节点有一个接触球，其半径也用于前一节点到该节点的场景扫掠胶囊；尾根没有前接骨段，仅有接触球和运动扫掠。虚拟末端不是额外的可蒙皮骨骼。分段粗细不是自动读取尾巴网格，也不是连续锥形碰撞体，需要按外形手动拟合。

线框和计算使用同一组参数：黄色突出当前调整项，橙色表示发生接触，受保护／关闭节点显示灰点；碰撞关闭时可用灰色线框预调形状。场景开启时胶囊显示最近实际执行的骨段扫掠范围，地面单独开启时只显示接触球。线框不受场景遮挡，只在本机显示。关闭设置窗口后自动隐藏；暂停接管或没有受支持尾链时不生成预览。

0.1.3 对检测、线框、骨段长度和修正写回使用完整的角色物理坐标变换，包含旋转和缩放。半径仍表示场景中的厘米，不随角色缩放再次放大。线框表示实际物理查询位置；原动画混合和网格蒙皮仍可能造成差异，不会通过单独平移线框来掩盖。

半径和保护开关在下一次物理更新时实时应用，不重建耳尾物理；旧版单半径配置自动迁移，保留中后段比例。耳尾档位和物理预设未改动。

### 随机耳尾小动作

打开 `/earphysics`，勾选「随机耳尾小动作（试验）」。静止约 3–5 秒后开始首次随机触发；之后每个部位在动作结束后休息约 2–7 秒，再选择下一种动作。耳朵和尾巴分别计时，同一部位不连续重复同一种动作，方向、幅度和时长会变化。

尾巴包括慢摆、尾尖轻挑和一次短促轻甩；耳朵包括左耳轻抖、右耳轻抖和双耳轻竖。长毛尾先转动 B 到 C 的靠根骨段，再带动中段和尾尖。尾根固定在原动画的位置。竖尾时，第一段也能向侧面摆。龙尾更克制。耳朵开关关闭时不添加耳部动作；尾巴选「原版对照」时不添加尾部动作。只有受支持且正在运行原生模拟的骨链才会响应。

移动或转身时，当前小动作约 0.35 秒淡出；重新静止后再开始随机计时。战斗、施法、骑乘、倒地、切区和过场时暂停。GPose 遵循现有暂停选项。关闭开关后停止添加动作目标，耳尾由原有物理自然收稳；切换此开关不重建物理。

插件在当前动画姿势上叠加动作，由游戏继续求解重量、阻尼和碰撞。动作期间，长毛尾、短毛／龙尾和耳朵分别将偏低的动画吸引系数平滑提高至最多 0.18、0.04 和 0.16，每次原生求解结束即恢复。耳部驱动仅作用于正在做动作的一侧或双侧。实际观感取决于模型的蒙皮权重、姿势和物理档位。

测试时先站立 20–30 秒观察完整动作与间隔，再跑停、转身、开关功能和靠墙对比。设置中显示当前动作；「运行状态（排查）」区分随机事件次数和实际动作目标应用次数，便于定位“已触发但未接入骨链”的情况。

## 首轮测试

更新 0.1.3 后先保持原有档位和半径，在不同朝向下检查线框与尾巴的对应位置，再接近实体墙面或地面。打开「运行状态（排查）」可分别查看原生场景／地面命中、无效结果和三角面法线补全次数。查询增长不等于命中，命中也不一定需要修正。预览开启时还显示物理点与动画混合位置的最大偏差，供继续定位视觉偏移。

1. 关闭旧物理包并重绘，插件选长毛／强惯性、自然耳朵，所有碰撞先关闭。
2. 对比待机、原地转身、跑停、跳跃和带尾巴动作的表情。确认耳尾分别切档有效，原动画可辨，急停没有持续回弹。
3. 开地面碰撞，在平地坐／躺、斜坡和平台边缘测试。设置中可查看场景查询及接触次数。
4. 再开场景碰撞和碰撞体预览，缓慢转身使中后段接近有碰撞的墙面／障碍。按外观分别调整节点半径，再分别试验取消尾根／靠根保护。
5. 检查换装、重绘、GPose 进入退出、传送，以及关闭／卸载插件后是否恢复。

若客户端未适配或接管校验失败，先查看设置中的状态。出现异常时关闭插件并重绘自身；安装测试版前保留已有物理包作为回退，但不要同时启用。

## 构建和验证

需要 .NET 10 SDK、Windows x64、国服 Dalamud API 15 的开发 DLL。

```powershell
./build.ps1 -DalamudLibPath 'C:\path\to\Dalamud\15.0.4.0'
dotnet run --project tests/Checks.csproj -c Release
```

输出为 `artifacts/EarTailPhysics.zip`。运行时只需要 DLL 和插件清单，不携带游戏资源、第三方 Mod 文件或 Dalamud DLL。

本地另在随机动作开启配置下，对 576 组既有 Mod 组合做了耳尾参数对照；仅将耳朵风系数的预期值调整为一半，其他比较项保持原样。这项检查需要用户自己的提取资源，原件不放入仓库。纯逻辑测试涵盖参数独立性、源数据不变、根部保护、接触半径、配置迁移、坐标变换、命中结果、自身范围校验、尾链重新绑定和风输入衔接。随机动作检查覆盖六种事件、30/60/144 FPS、移动／暂停、耳尾独立性、目标段长、临时驱动边界及逐次完整恢复；简化吸引响应检查用于防止弱跟随再次吞掉短动作。**这些结果不等于实际游戏调用或视觉测试通过。**
